# Materiais de referência

Coloque aqui o material bruto que os subagentes usam para criar aulas.

| Pasta | O que vai nela |
|---|---|
| `pdfs/` | artigos, apostilas, slides, notas de aula |
| `livros/` | livros (PDF, EPUB) |
| `codigo/` | scripts, notebooks (`.ipynb`), exemplos em Qiskit/PennyLane |
| `links.txt` | sites e páginas úteis, um por linha |

- Os arquivos dentro de `pdfs/`, `livros/` e `codigo/` **não vão para o git** (direitos autorais; o repositório é público). Só esta estrutura, o README e o `links.txt` são versionados.
- Conteúdo gerado a partir daqui deve ser original: cite a fonte, nunca copie.
- Para testar: coloque um PDF em `pdfs/` e peça `/maestro transforme referencias/pdfs/<arquivo>.pdf em aula`.
